# 🧠 Artificial Intelligence Projects

This repository contains multiple AI-related projects developed during training at **Benchmark IT Solutions**, covering areas of **Computer Vision**, **Optical Character Recognition (OCR)**, and **Artificial Neural Networks (ANNs)**. Each project focuses on solving real-world problems using AI/ML concepts with Python and relevant tools.

---

## 📁 Project List

### 1. [OCR-Based Image and PDF File Conversion to CSV](./ocr-to-csv)
**Skills Used:** Python, OpenCV, Tesseract, EasyOCR, Image Preprocessing, CSV Conversion, Google Colab, LaTeX  
Automates the extraction of tabular data from scanned PDFs/images (Marathi/Hindi/English) and converts it into structured CSV using OCR, OpenCV, and translation models.

### 2. [Computer Vision Mini-Projects](./computer-vision)
**Skills Used:** Python, OpenCV, NumPy, Image Processing, Contour Detection, Object Recognition  
Includes multiple small-to-medium scale image processing projects like edge detection, shape recognition, color masking, and image segmentation using classical CV techniques.

### 3. [Artificial Neural Networks (ANN) Projects](./ann-projects)
**Skills Used:** Python, NumPy, Scikit-learn, TensorFlow/Keras  
Basic to intermediate projects focused on implementing and training neural networks for classification/regression problems, including hand-written digit recognition (MNIST), XOR gate classification, etc.

---

## 🧠 Key Skills Demonstrated

- **Languages & Tools:** Python, Jupyter, Google Colab, OpenCV, Tesseract, EasyOCR, NumPy, Pandas, Scikit-learn, Keras
- **AI/ML Concepts:** OCR, Computer Vision, Table Detection, ANN Basics, Classification, Preprocessing Pipelines
- **Soft Skills:** Problem-solving, Technical Writing, Research Analysis (with LaTeX), GitHub Documentation
